# 연차 계산기

한국석유관리원 취업규칙(제18차개정 2025.12.29)을 기준으로, 입사연월일을 넣으면 매년 만근했을 때 연차가 몇 개 생기는지 계산합니다.

- 제32조① 15일 + 최초 1년을 초과하는 계속근로 매 2년마다 1일, 최대 25일
- 제32조② 1년 미만은 1개월 개근 시 1일
- 제32조④ 부여기준일 1월 1일 (회계연도 기준), 입사 다음 해 1월 1일에는 입사한 해 근무일수에 비례한 연차
- 미리 쓰기 한도(제32조⑫), 저축 가능 일수(제33조의2), 장기재직휴가(제36조⑲)도 같이 보여 줍니다.

참고용입니다. 휴직·결근은 반영하지 않으며, 정확한 일수는 ERP에서 확인하세요.
